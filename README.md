# money-games

The built Kids Money Games site, published with GitHub Pages. Everything here comes from a build of the private `kids-money-games` repo (see its `DEPLOY.md`), except:

- `privacy.html`: the privacy policy for every game, including the Amazon Fire tablet apps. It is added by hand and is not part of the build. When deploying, copy the build over this folder; never empty the folder first, or this page is lost and the Amazon listings' privacy link breaks.
